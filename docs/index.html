SO Mini Dashboard

A local, read-only dashboard for Stellar Odyssey. Resources, lab queues, market prices, progress and today's best solo dungeons, on one page.

Download for Windows Source on GitHub

Read-only. It never buys, sells, queues, claims, cancels or sends input to the game. It serves one page on 127.0.0.1 only, and uses the game's own sign-in without copying any password or cookie out.

What it shows

  • Resources: every currency and material, change per hour, and value at the best market buy order.
  • Lab: each lab and base building, queue progress and finish time in your local time, with optional desktop alerts.
  • Market: best buy and sell order, spread and depth for each resource.
  • Dungeons: which solo dungeon entrances pay the most relics today, with coordinates, distances and an upgrade what-if.
  • Progress: net worth over time, income per hour, skill XP rates, and the weekly minigame leaderboards with your entry.

Run it

  1. Download SO-Mini-Dashboard.exe from the latest release.
  2. Start Stellar Odyssey.
  3. Double-click the exe. The dashboard opens in your browser. Close its window to stop it.

If Windows says "Windows protected your PC", click More info, then Run anyway (the file is not code-signed). A green Update available badge appears next to the version when a newer release is out.
